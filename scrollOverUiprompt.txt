Task: Implement a Mobile-Only "Sticky Overlap & Fade" Hero Transition

1. Core Concept: Create a hero section for a mobile landing page where the text interface remains "frozen" (sticky) in the viewport while the main product images (slideshow/mockup) scroll up and pass over the text. As the images cover the text, the text should fade out.

2. Layout Requirements (Mobile):

Navbar: Sticky at the top of the screen (z-index 100).
Hero Content (Text): Contains a badge, H1 title, paragraph, and CTA buttons. On mobile, this container must be position: sticky and locked near the top (e.g., top: 15vh).
Hero Image (Mockup): Positioned below the text in the initial view. It needs a larger margin-top (e.g., 60vh) to ensure the text is visible first. It must have a higher z-index than the text so it slides over it.
3. Interaction & Animation Logic:

Scroll Depth: The Hero container must be very tall (e.g., min-height: 200vh) to allow enough room for the overlap animation before normal scrolling resumes.
Fade-Out Trigger: Use a scroll listener or CSS scroll-driven animation. When the user scrolls past a threshold (e.g., 200px or 40vh), trigger a transition that sets the opacity of the H1, paragraph, and buttons to 0 and adds a subtle translateY(-20px) effect.
Sticky Release: The sticky text should automatically "release" and scroll away once the user reaches the bottom of the tall hero container.
4. Styling & Aesthetics:

Theme: Dark mode with cinematic gradients.
Glassmorphism: Use backdrop-filter: blur() on the sticky navbar to maintain readability when images pass behind it.
Transitions: All visibility changes (opacity/transform) should use a smooth ease-in-out transition (e.g., 0.3s ease).
5. Constraints:

The layout must return to a standard side-by-side or stacked layout on Desktop screens (ignore the sticky overlap effect for larger resolutions).
